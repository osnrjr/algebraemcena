Regra de Cramer

Escreva o sistema como A · X = K. Calcule D = det(A). Para cada incógnita, troque a sua coluna em A pela coluna K, mantendo as outras colunas no lugar, e calcule o determinante: Dx, Dy, Dz. Se D ≠ 0, cada incógnita vale Dⱼ / D.

  • 2×2 (produto cruzado): D = a₁₁·a₂₂ − a₁₂·a₂₁.
  • 3×3 (Sarrus): repita as duas primeiras colunas à direita; some os três produtos descendentes e subtraia os três ascendentes.
  • Dz em 3×3 é [a₁₁ a₁₂ K₁; a₂₁ a₂₂ K₂; a₃₁ a₃₂ K₃]: só a 3ª coluna muda.

Escalonamento (operações elementares)

  • E1 troca de linhas: L1 ↔ L2
  • E2 multiplica uma linha por c ≠ 0: L2 ← (1/3)·L2
  • E3 soma o múltiplo de outra linha: L2 ← L2 + 2·L1
  • E4 combinação sem frações: L2 ← 3·L2 − 2·L1

Classificação

r = posto(A), r′ = posto([A | K]), n = número de incógnitas.

SPD
r = r′ = n: uma única solução.
SPI
r = r′ < n: infinitas soluções, com n − r parâmetros livres.
SI
r < r′: aparece uma linha 0 = c com c ≠ 0; nenhuma solução.

Atenção: D = 0 não decide sozinho. O sistema x + y + z = 1, x + y + z = 2, x + y + z = 3 tem D = Dx = Dy = Dz = 0 e é impossível.
